# КАССЕТЫ - Расстановка зданий по слотам (как в Travian Legends)

## Нумерация слотов - оригинал
В файле `village_center_authentic_travian.png` видно классическую нумерацию 1-22:
- Слот 1 - центр-север внутреннего кольца (чуть южнее Главного)
- Слоты 2,3,4,5,6,7,8 - внутреннее кольцо
- Слоты 10-22 - внешнее кольцо
- Главное Здание - фиксировано на севере за слотом 1 (ворота)
- Пункт Сбора - фиксировано на востоке
- Стена - по кругу

## Оптимальная расстановка для нашей игры (Android)

### СТАРТ (День 1) - как на `village_center_starter_stage.png`
Слот 1: Главное Здание lvl 6 - центр север, всегда тут
Слот 2: Склад lvl 3 - северо-запад, рядом с ГЗ чтобы не бегать за ресурсами
Слот 3: Амбар lvl 3 - северо-восток
Слот 4: Казарма lvl 1 - запад, ближе к выходу чтобы войска быстро выходили
Слот 5: Пункт Сбора lvl 1 - восток (фиксировано)
Слоты 6-22: Пусто (показываем молотком - можно строить)

**Логика топ-игроков:** Сначала качаем склад/амбар чтобы не сгорали ресурсы, потом казарму.

### ЛЕЙТ (День 60) - фулл деревня
Все то же, но:
- ГЗ 20, Склад/Амбар 20, Стена 20
- Резиденция -> Дворец 20 (если столица)
- Ратуша 15, Сокровищница 10
- Казарма/Конюшня/Мастерская 20
- Кузница/Доспехи 20

### Почему так расставляем (мета Travian):
1. **Военка на востоке** - ближе к Пункту Сбора, быстрее анимация выхода войск
2. **Экономика на юге** - Рынок/Резиденция/Ратуша рядом, удобно для праздников
3. **Склады на севере** - рядом с ГЗ, ГЗ ускоряет их прокачку
4. **Бонусные здания** - раскиданы, но Мельница+Пекарня рядом с амбаром для логики (+75% к зерну)

### Для Unity реализация:
В `BuildingConfigSO` добавь поле `slotIndex` 1-22 и `isFixed` для Главного и Пункта Сбора.
В префабе деревни создай 22 Transform'а `Slot_01` ... `Slot_22` расставленных по кругу как на картинке.
При загрузке сохранения: `Instantiate(buildingPrefab, slotTransform.position)`

Скрипт `VillageView.cs`:
```csharp
Dictionary<int, BuildingSlot> slots; // 1-22
void PlaceBuilding(BuildingData data){
  var t = slots[data.slotId].transform;
  var go = Instantiate(GetPrefab(data.type), t.position, Quaternion.identity, t);
  go.GetComponent<BuildingVisual>().SetLevel(data.level);
}
```

### 1. ФОРМУЛЫ ДОБЫЧИ

**Базовая добыча полей:**

Для всех ресурсов формула одинаковая, но база разная.

```
Production(Lvl) = Base * Factor^Lvl + Offset
```

**Суммарная добыча деревни (на 4-4-4-6):**
- На старте (все lvl1): ~ (5*12 +5*6)= 60+30=90 каждого прим + 30 зерна = капельно, но хватает на рост.
- На мидгейме (все lvl10): Дерево 1200, Глина 1200, Железо 1200, Зерно 2220 в час.
- На лейте (поля 15, столица 10-10-10-17): ~ 5000 каждого + 12000 зерна до бонусов.

**Бонусные здания:**
```
Final = BaseProduction * (1 + MillBonus) * (1 + OasisBonus) - Consumption
MillBonus: 0.25 (Лесопилка) или 0.25+0.5=0.75 для зерна.
OasisBonus: 0.25 за один оазис 25%, 0.5 за 50%. Макс 3 оазиса: +75% или +37%+25%+25% если разные.
```

### 2. СКЛАДЫ И АМБАРЫ

**Вместимость:**

### 3. СТОИМОСТЬ ЗДАНИЙ ЦЕНТРА

Базовая стоимость для примера:

```
Main Building Lvl1: 70W 40C 60I 20Cr
Barracks Lvl1: 210W 140C 260I 120Cr
Market Lvl1: 80W 70C 120I 70Cr
Academy Lvl1: 220W 160C 90I 40Cr
Residence Lvl1: 120W 200C 180I 100Cr - но Lvl10 стоит уже 12k каждого реса
```

Рост стоимости: `Cost(n) = Cost(n-1) * 1.28` (как в Травиане 1.25-1.35)

Время стройки:
```
Time = (Sum_resources / 2.5) * 1.3^(lvl-1) / (1 + MainBuildingLvl*0.05)
Но не меньше 30 сек.
```
Пример: ГЗ 1 lvl = 190/2.5 =76 сек, +20c = ~75 сек.
ГЗ 10 lvl = ~ 2 часа.

### 4. НАСЕЛЕНИЕ И ПОТРЕБЛЕНИЕ ЗЕРНА

Каждое здание дает население (очки рейтинга). Каждый юнит тоже.
Население = потребность в зерне.

```
Crop Consumption = sum(population_buildings) + sum(units * crop_eat)
```

Если баланс:
- + : зерно накапливается
- - : зерно убывает, если до 0 - начинается голод.

**Голод:**
Если `CropStored == 0 && NetConsumption < 0`, каждые 10 минут умирает 1 юнит (самый дешевый сначала) и снижается лояльность деревни на 1%.

### 5. CULTURE POINTS (CP)
Нужно для основания/захвата деревень.

Дают:
- Все здания: CP = население * коэф. (ГЗ дает больше, ратуша еще больше)
- Праздники в ратуше.

Требования на N-ую деревню:

| Деревня № | CP Требуется накопить |
|-----------|-----------------------|
| 2         | 500                   |
| 3         | 2000                  |
| 4         | 7000                  |
| 5         | 18000                 |

CP не тратится, а накапливается как опыт. Когда накопил 500 и есть 3 поселенца - можешь основать.

### 6. ТОРГОВЦЫ

Грузоподъемность по племени.
Скорость: 16 полей/час базовая.
Формула времени: `Time_hours = Distance / Speed`

Distance - евклидово: `sqrt((x1-x2)^2 + (y1-y2)^2)`

Торговцы возвращаются назад с пустыми руками.

### 7. ОФФЛАЙН ПРОДАКШН КАЛЬКУЛЯЦИЯ

**Кейс 1: Игрок офлайн 8 часов, добыча 1000/час, склад 7800.**
Зашел - прошло 8ч, должно было добыться 8000, но склад только 7800, значит получит 7800 и встанет.

Код псевдо:

```csharp
TimeSpan offline = DateTime.UtcNow - save.lastSave;
double hours = offline.TotalHours;

foreach (village in villages) {
  foreach (res in [W,C,I,Cr]) {
    double freeSpace = warehouseCap - resStored;
    double prod = village.GetProdPerHour(res) * hours;
    village.AddRes(res, Math.Min(freeSpace, prod));
  }
  // Голод
  if (village.CropStored ==0 && village.NetCrop <0) {
    int steps = (int)(offline.TotalMinutes / 10);
    village.ProcessStarvation(steps);
  }
  // Стройки
  while (village.buildQueue.Count>0 && village.buildQueue[0].finishTime <= now) {
    village.FinishBuild();
  }
  // Походы
  foreach (movement in movements) {
    if (movement.arriveTime <= now) movement.Arrive();
  }
}
```

**Важно:** Сохранять игру при каждом действии и каждые 30 сек автосейв.

### 8. АНТИ-ЧИТ ДЛЯ ОФФЛАЙНА
Игрок может перевести часы телефона вперед. Решение для MVP не критично, но добавим проверку:
- Если `offline.TotalHours > 72` - считаем максимум 72ч добычи (не больше 3 дней)
- Если `offline.TotalHours < 0` (время назад) - не даем ресы, сбрасываем.

# TRAVIAN ANDROID OFFLINE - Game Design Document v1.0

**Жанр:** Стратегия, градостроитель, MMO-like offline first
**Платформа:** Android (Unity 2022 LTS)
**Стиль:** Античность (Римляне, Галлы, Германцы) / Мультяшная изометрия как в Travian: Kingdoms + Clash of Clans
**MVP:** Полный оффлайн цикл - экономика, армия, 2-3 деревни, герой, PvE-лагеря

---

### 1. HIGH CONCEPT
Игрок - вождь маленькой деревни в античном мире. Начинает с 4 полей и пустого центра. Добывает 4 ресурса, строит 20+ типов зданий, исследует войска, грабит лагеря разбойников, захватывает оазисы, основывает новые деревни. Все работает оффлайн. Время идет даже когда игра закрыта (через дельту времени).

Это Travian, но без доната и ожидания других игроков. Идеально для телефона в метро.

### 2. CORE LOOP (30 сек - 5 мин - 2 часа)
**Короткий (30 сек):** Зашел -> Собрал ресы -> Запустил постройку -> Запустил войска в набег.
**Средний (5-15 мин):** Проверил отчеты -> Прокачал поля -> Отбил атаку разбойников -> Прокачал героя.
**Длинный (2-4 часа / дни):** Накопил КП -> Основал 2-ю деревню -> Вышел в топ по популяции -> Открыл сенатора.

`Ресурсы -> Постройки -> Армия -> Больше ресурсов/территорий -> Ресурсы`

### 3. СЕТТИНГ И ПЛЕМЕНА
3 племени, выбор при старте. Меняет внешний вид деревни, бонусы и юнитов.

**1. Римляне (баланс, для новичков):**
Бонус: +10% к защите построек стеной, постройки на 10% быстрее строятся одновременно с полями, торговцы несут 500 рес. Пехота сильная, но дорогая.
Стена: Городская Стена.

**2. Галлы (оборона, скорость):**
Бонус: +20% вместимость тайника, +30% скорость торговцев, 2-й воствой тайник от галльского народа. Лучшие защитники.
Стена: Земляной Вал, бонус к защите в 2 раза выше.
Торговцы 750 рес.

**3. Германцы (атака, дешево и сердито):**
Бонус: Тайник 0 у врага (грабят все), +10% бонус к грабежу, дешевые войска. Слабый деф.
Стена: Частокол, дает меньше защиты, но проще строить.
Торговцы 400 рес.

### 4. РЕСУРСЫ
4 базовых:
- `WOOD` (Дерево) - лесопилка
- `CLAY` (Глина) - глиняный карьер
- `IRON` (Железо) - железный рудник
- `CROP` (Зерно) - ферма

И вторичные:
- `POPULATION` - население (требует зерна)
- `CULTURE POINTS (CP)` - очки культуры для основания деревень
- `GOLD` (в будущем - прем валюта)

**Баланс добычи:**
`Production_per_hour = base * (1.05 ^ level) ` или по таблицам Travian: Lvl0=2, Lvl1=10, Lvl10=400 и т.д.

Потребление зерна = сумма населения всех зданий и войск.

Если зерно < 0 = голод, войска начинают умирать.

**Склады:**
`Capacity_warehouse = 800 * (1.2 ^ level)`
`Capacity_granary = 800 * (1.2 ^ level)` + модификаторы от хлебопекарни/мельницы не увеличивают вместимость, а бонусят к производству.

### 5. СТРУКТУРА ДЕРЕВНИ

**А) Ресурсная зона (круг вокруг):**
18 полей. Тип карты сетапа:
- Классика для старта: 4 дерево, 4 глина, 4 железо, 6 зерна (4-4-4-6)
- Редкие: 3-4-5-6, 3-3-3-9 (кропер, где 9 ферм - имба для военки)

Игрок тапает на поле -> апгрейд.

**Б) Центр деревни (22 слота + стена):**
Слот 0 = центральное здание всегда - Главное Здание
Слоты 1-20 - любые здания
Слот 21 - Стена (ралли поинт + стена считаются обязательными)
Слот 22 - Ралли Поинт (пункт сбора) - по центру.

**В) Оазисы:** На глобальной карте. Дают +25% или +50% к одному ресурсу если захватить героем и чистить природу.

### 6. ЗДАНИЯ - КРАТКИЙ СПИСОК (подробно в Buildings.md)

**Инфраструктура:**
1. Главное Здание (ускоряет стройку)
2. Склад
3. Амбар
4. Тайник (прячет ресы от грабежа)
5. Рынок
6. Посольство (в оффлайне - дает бонусы к КП)
7. Резиденция / Дворец (для поселенцев и захвата)
8. Ратуша (праздники для КП)
9. Сокровищница (для артефактов, в будущем)
10. Торговая Палата (ускоряет торговцев)

**Военные:**
11. Пункт Сбора (для походов)
12. Казарма (пехота)
13. Конюшня (кавалерия)
14. Мастерская (катапульты, тараны)
15. Академия (исследование войск)
16. Кузница (апгрейд атаки)
17. Фабрика Доспехов (апгрейд защиты)
18. Стена / Вал / Частокол
19. Траппер (только у галлов) / Западня
20. Арена (для героя)

**Экономические бонусы:**
21. Лесопилка (+25% к дереву на 5 ур)
22. Кирпичный Завод (+25% глина)
23. Литейный Завод (+25% железо)
24. Мукомольная Мельница (+25% зерно)
25. Пекарня (+50% к зерну, стак с мельницей = +75%)

Логика: бонусные здания работают только если все поля одного типа >=10 уровня и бонусное здание на 5 уровне.

### 7. АРМИЯ И БОЕВКА

**Типы юнитов:** 10 на племя: 6 обычных, 2 разведчика/кава, 1 осада, 1 админ (поселенец/сенатор/вождь).

**Обучение:** Через казарму/конюшню/мастерскую. Стоимость + время. Можно в очередь.

**Боевая система (типичная Travian):**
Каждый юнит имеет: Atk vs пех, Atk vs кав, Def vs пех, Def vs кав, скорость, грузоподъемность, потребление зерна.

Формула упрощенная для MVP:

1. Считаем суммарную атаку всех атакающих (с бонусами кузницы, героя, стены нет у атакера).
2. Считаем суммарную защиту дефендера (Def vs Inf + Def vs Cav раздельно, + бонус резиденции + стены).
3. `Wall Bonus = (Wall Level * TribeWallFactor)` e.g. Рим 1.03^lvl
4. Ранд 0.9-1.1 разброс.
5. Потери по формуле Lanchester.

Простой вариант MVP: `Power = sum(attack) / sum(defense)`. Если >1 - атакующий победил с потерями.

**Типы атак:**
- Набег (грабеж только, без захвата, без смерти дефа в поле)
- Атака (уничтожение)
- Разведка

**PvE:** Лагеря разбойников на карте (как в Kingdoms). Респавнятся каждые 8 часов. Дают ресы и опыт герою. 15 уровней сложности.

### 8. РАСШИРЕНИЕ

Чтобы основать 2-ю деревню:
1. Культура: нужно накопить КП. Дают все здания (особенно ратуша праздники).
2. 3 поселенца (из резиденции lvl 10)
3. 750 каждого реса у поселенцев.

Захват чужих деревень (NPC): нужен Сенатор / Вождь / Старейшина. Снижает лояльность с 100 до 0. 3-4 похода.

Лимит деревень: оффлайн сделаем 5 макс для MVP.

### 9. ГЕРОЙ И ЗАДАНИЯ

**Герой:** 1 на акк. Ходит с войсками или один. Имеет атрибуты: Сила (атака), Защита, Ресурс-бонус. Прокачка до 100 лвл. Экипировка (шлем, броня, сапоги ускорения и т.д).

**Инвентарь:** падает с лагерей разбойников.

**Система заданий (Tutorial):** 30 заданий по цепочке как в Травиане - "Построй лесопилку до 2 lvl" -> награда ресами. Держит игрока первые 2 часа.

### 10. КАРТА
Размер для оффлайна: 401x401 клетки (координаты -200..200).
В центре спавн игрока.
Генерируется шумом:
- 1000 пустых клеток
- 500 лагерей разбойников разного уровня
- 200 оазисов (с природой)
- 100 NPC-деревень (фермы для грабежа)
- 50 свободных мест для основания.

Карта - 2D grid, клик -> инфо -> отправить войска / поселенцев / героя.

### 11. ОФФЛАЙН ЛОГИКА И СОХРАНЕНИЯ
Ключевая механика!
Игра должна работать без интернета.

При выходе: `PlayerPrefs.Save + JSON Save File -> lastTimestamp = DateTime.UtcNow`

При входе: `delta = Now - lastTimestamp`
Для каждой деревни:
`produced = production_per_hour * delta_hours`
Прибавить к ресурсам, но не больше склада.
Если потребление зерна отрицательное -> посчитать голодание.

Строительные очереди: проверить, если `endTime <= Now` -> завершить постройку, запустить след. в очереди.

Военные походы: если возврат уже наступил во время оффлайна - вернуть войска.

Используем Unity `Application.quitting` + автосейв каждые 30 сек.

Сохранение: локальный JSON + ScriptableObjects для конфигов. Позже прикрутим Firebase / Play Games для клауда.

### 12. UI/UX ДЛЯ ANDROID
Портретная ориентация (как в Kingdoms).

**Навигация (5 табов снизу):**
[Ресурсы] [Деревня] [Карта] [Отчеты] [Герой/Профиль]

**Верхний бар всегда:** 4 ресурса (древо/глина/железо/зерно) + свободное зерно + вместимость. Прогресс-бар до заполнения.

**Экран Ресурсов:** Круглая карта полей, по тапу - ап. В центре иконка деревни.

**Экран Центра:** Изометрическая сетка 3D деревни. Здания на слотах. Тап - меню постройки.

**Экран Карты:** Зумируемая 2D карта. Кнопка "Центрировать на моей деревне".

**Экран Отчётов:** Входящие / исходящие атаки, грабежи, система.

### 13. АРТ-ДИРЕКШН
Cartoon Isometric, яркие цвета, читаемые силуэты.
Палитра: Теплая (песок, дерево) + зеленый для зерна.
Здания: 3 уровня визуала (1-5, 6-15, 16-20) для оптимизации.
Перспектива: 45 градусов, как в CoC.

Эффекты: дым из трубы лесопилки, пыль на карьере - живые поля.

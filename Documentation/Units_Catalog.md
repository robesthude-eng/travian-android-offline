## Механика тренировки
Казарма - пехота (1-3), Конюшня - кава + разведка (4-6), Мастерская - осада (7-8), Резиденция - поселенец/админ (9-10)
Требуется Академия для исследования юнита. Кузница/Фабрика доспехов дают +1.5% атаки/защиты за уровень.

В Unity:
- BuildingConfigSO: Barracks lvl 3 открывает Praetorian
- UnitConfigSO: requiredBuilding=barracks, requiredLevel=3
- TrainingQueue: очередь на каждый корпус, время = baseTime * 0.9^barracksLevel

**Особенность:** Могут строить поле ресурсов и здание в центре одновременно (бонус ГЗ). Сильная пехота, защита средняя. Дорого.

**Особенность:** Бонус к тайнику, быстрый торговец, траппер. Лучший деф, дорогие катапульты. 
- Торговцы: 750 рес, скорость 24 (самые быстрые)
- Стена: 1.025^lvl, но базовый бонус в 2 раза выше римской
- Траппер

### Германцы - "Ярость Севера"
**Особенность:** Дешевые юниты, сильный грабеж (тайник врага не работает), слабые торговцы и стена.
- Торговцы: 400 рес, скорость 12
- Стена: 1.02^lvl, слабый бонус

## 3. БОЕВАЯ ФОРМУЛА MVP (УПРОЩЕННАЯ)

Чтобы не писать полный симулятор Travian (там 1000 строк), для MVP делаем так:

**Вход:** 
- Атакующий: Lys A = [unitType:count]
- Защитник: Lys D = [unitType:count] + стена + резиденция + герой

**Шаг 1: Суммарная атака и защита**

```
TotalAtk = Σ (count_i * Atk_i * (1 + SmithLvl*0.015) * HeroBonus)
TotalDefInf = Σ (count_j * DefInf_j * (1 + ArmourLvl*0.015) * WallBonus)
TotalDefCav = Σ (count_j * DefCav_j * (1 + ArmourLvl*0.015) * WallBonus)
```

Если в атаке есть и пехота и кавалерия, то деф делится пропорционально.

Упрощение MVP: `TotalDef = TotalDefInf*0.5 + TotalDefCav*0.5`

**Шаг 2: Бонус стены**

```
WallBonus = 1 + WallLevel * WallFactor
WallFactor: Rome=0.05, Gaul=0.08, Germ=0.03
Например: Рим Стена 10 = 1 + 10*0.05=1.5 => +50% к защите
```

**Шаг 3: Расчёт соотношения**
```
Ratio = TotalAtk / TotalDef
Random = 0.9..1.1
Ratio *= Random
```

**Шаг 4: Определение победителя и потерь**

```
Если Ratio > 1: Атака победила.
   Defender Losses = 100%
   Attacker Losses = (1 / Ratio) * 100% * MoraleFactor
   Например Ratio 1.5 => атакер теряет 66% своих

Если Ratio <=1: Защита победила.
   Attacker Losses = 100%
   Defender Losses = Ratio * 100%
```

MoraleFactor = 1 если атака на разбойников, 1.2 если на игрока (чтобы не было слишком мясорубки).

**Шаг 5: Грабеж**
Если атака победила и тип атаки "Набег":

```
Loot = Σ (Грузоподъемность выживших юнитов атаки)
Награблено = min(Loot, Resources_in_village - CrannyProtected)

Распределение: пропорционально ресурсам в деревне.
```

**Пример:**
100 Легионеров (груз 50) = 5000 груз. Выжило 40 = 2000 груз.
В деревне врага: 3000 дерева, 1000 глины. Тайник защищает 500.
=> Можно унести 2000, реально: 1500 дерева, 500 глины (пропорционально 3:1).

**Шаг 6: Осада**
Тараны ломают стену: `WallDamage = NumRamsAlive * 0.2` уровней (макс -3 за атаку)
Катапульты ломают случайное здание: Требуется >50% катапульт выжило. Шанс 70%. Ломает на 1-2 уровня.

### 4. NPC-ПРОТИВНИКИ (PvE)

**Лагеря разбойников (Robber Hideouts):** Главный фарм.

| Уровень лагеря | Войск (Природа) | Награда ресов | Опыт герою |
|----------------|-----------------|---------------|------------|
| 1 | 5 крыс | 300 | 50 |
| 2 | 15 крыс + 5 пауков | 800 | 100 |
| 3 | 10 пауков + 5 змей | 1800 | 180 |
| 5 | 30 змей + 10 диких зверей | 5000 | 350 |
| 10 | 100 зверей + 20 разбойников | 25000 | 1000 |
| 15 (Босс) | 300 разбойников + герой | 100000 | 5000 |

Природа - отдельные юниты, чуть слабее игроковых, без бонусов кузницы.

Респавн: Каждые 8 часов на случайных координатах в радиусе 30 полей от игрока.

**Оазисы:**
Захвачено природой: 50-500 зверей. После очистки нужен герой в деревне чтобы присоединить.
Дает бонус +25% или +50%. Можно иметь 3 оазиса на деревню.

**NPC деревни (Фермы):** Слабые деревни с 200 населения, без стены, с 2-3к ресов внутри, ресаются каждые 12 часов.

### 5. ГЕРОЙ В БИТВЕ

Герой дает +20% к атаке/защите всем войскам если идет с ними. + (Сила * 0.5%) бонус.

Если герой погибает в бою - попадает в больницу (в ратуше? в геройском дворе) на 1 час + можно воскресить за ресы.

Опыт героя: +10xp за убитого юнита врага.

Прокачка: Каждые 100xp = 1 lvl, 1 очко атрибутов. Очки в силу / защиту / бонус добычи / скорость.

### 6. РАЗВЕДКА

Разведчики сражаются только с разведчиками.
Формула: если атакующий разведчиков больше чем у защитника - разведка успешна, видит ресы и войска.

Если нет - разведчики умирают, защитник получает отчет "На вас пытались разведать".

### 7. ЛОГИКА ПОХОДОВ

Каждый поход - объект `Movement`:

```
{
 id,
 fromVillage,
 toPosition (x,y),
 troops: {type:count},
 hero: bool,
 type: "raid/attack/scout/settle",
 arriveTime: DateTime,
 returnTime: DateTime,
 isReturning: false,
 loot: {W,C,I,Cr}
}
```

Расчет времени:

```
Distance = sqrt((x1-x2)^2 + (y1-y2)^2)
Speed = minSpeed_of_troops (самый медленный юнит)
TravelTime_hours = Distance / Speed * ServerSpeed (1.0 для MVP)
```

На клиенте: список движений внизу экрана карты, таймер.

При оффлайне: при загрузке проверяем `now > arriveTime` => обрабатываем бой, затем ставим `returnTime = arriveTime + TravelTime`.

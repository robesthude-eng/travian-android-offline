# Travian Offline — Godot 4

Оффлайновая стратегия в духе Travian под Android. Полный цикл — экономика,
строительство, армия, бой, герой, вторая деревня — плюс живые соперники:
эвристические боты и, по желанию, вожди под управлением языковой модели.

## Как получить APK

Сборка идёт в GitHub Actions, локально Godot не нужен.

1. Actions → **Build Android APK (Godot)** → последний успешный запуск.
2. Artifacts → `travian-offline-apk-<номер>` → скачать zip.
3. Внутри `travian-offline.apk`. На телефоне разрешить установку из неизвестных
   источников и поставить.

Пуш тега `v*` дополнительно прикладывает APK к релизу.

### Одни часы на всё

Весь мир двигает одна функция — `Sim.advance_to(state, t)`. Она идёт по
событиям (достройка, обучение, прибытие войск, ход бота, голод), между
событиями начисляя ресурсы линейно: производство на интервале постоянно по
построению, поэтому это точный расчёт, а не приближение.

Живая игра и оффлайн-догон вызывают **одну и ту же** функцию. Восемь часов
игры и восемь часов с закрытым приложением дают идентичный мир. Отдельной
«оффлайн-ветки», которая может разойтись с основной, просто не существует —
это проверяется тестом `_test_offline_equals_online`.

### Состояние — обычный JSON

`state` это дерево из Dictionary / Array / float / String. Сохранение — это
`JSON.stringify`, загрузка — `JSON.parse_string`. Нет слоя сериализации,
который мог бы молча потерять словарь войск или отметку времени.

Производные величины (добыча, население, вместимость, культура в час)
**никогда не хранятся** — они вычисляются из состояния по запросу, поэтому не
могут разойтись с ним.

### Соперники

`Bots` — это абстрактная экономика плюс **настоящая армия**. 24 соперника
дёшево прокручиваются через 72-часовой догон, но их войска дерутся тем же
кодом `Combat`, что и твои, и их можно грабить.

Рейд бота соразмеряется с твоей реальной обороной, поэтому ранняя игра
переживаема, а заброшенная — наказуема. Первые 3 игровых часа боты не трогают
новичка.

### Живой соперник (Claude API)

Настройки → «Живой соперник». Модель **не управляет симуляцией напрямую**: она
возвращает *политику* (агрессивность, на что тратиться, реплика в характере),
которая кладётся на бота, а исполняет её детерминированный код.

Отсюда три следствия:

* без ключа и без интернета игра работает полностью;
* оффлайн-догон остаётся детерминированным и мгновенным;
* если запрос завис или упал, бот просто продолжает играть по эвристике.

Ключ хранится в сохранении на устройстве. Для личной сборки это нормально; в
магазин с общим ключом такое выкладывать нельзя.

## Отличия от исходного GDD

* Карта 121×121 вместо 401×401, содержимое сосредоточено в радиусе ~50 полей.
  На телефоне важнее плотность, чем размах: на исходной карте до ближайшего
  лагеря пришлось бы идти часами.
* Боты заменяют «100 NPC-деревень» — они интереснее, потому что растут и
  отвечают.
* Множитель темпа (1x/3x/5x/10x) выбирается при старте и меняется в настройках.
  По умолчанию 3x.

## Тесты

```
godot --headless --script res://game/tests/Tests.gd
```

15 групп: таблицы данных, формулы, боёвка, добыча, очереди, обучение, голод,
походы, боты на длинной дистанции, правила основания деревень, round-trip
сохранения и защита от перевода часов. CI не соберёт APK, если тесты упали.

## Старые ветки проекта

`AndroidSimple/` (WebView-прототип), `Assets/_Game/` (нерабочие Unity-скрипты) и
`Documentation/` оставлены как есть. Unity-воркфлоу удалён: он указывал на
несуществующую папку `UnityProject/` и требовал лицензионные секреты, которых
нет. Дизайн-документы в `Documentation/` по-прежнему актуальны — по ним и
собрана эта реализация.
